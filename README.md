# 🍳 Recipe Book

A simple and interactive **Recipe Book web application** built using React. The application allows users to explore different recipes, view ingredients and cooking instructions, and enjoy a clean and user-friendly recipe browsing experience.

---

## 📌 About the Project

**Recipe Book** is a React-based Single Page Application designed to organize and display recipes in an easy-to-use format.

The project focuses on creating a clean interface where recipes can be presented with important information such as:

* Recipe name
* Description
* Preparation/cooking time
* Difficulty level
* Ingredients
* Cooking instructions

The recipes include both classic dishes and creative homemade recipes such as **Pizza Dosa** and **Mom's Special Recipes**.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com
```

### 2. Open the Project Folder

```bash
cd Recipe-Book
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

After running the command, Vite will provide a local URL in the terminal.

Open that URL in your browser to use the Recipe Book.

## 📖 How to Use

1. Open the Recipe Book application.
2. Browse the available recipes.
3. Select a recipe to view its details.
4. Check the ingredients and their quantities.
